# MOEIS Kehadiran 一键点名

MOEIS 教师日常点名提速工具。绕过全部级联菜单，把"多点 6-8 下"变成"点 1 下"。

## 问题背景

原本每天点名流程：
1. 登录 idMe（输 IC + 密码 + 安全确认勾选）
2. idMe 应用列表 → Pengurusan Murid
3. MOEIS 首页 → hover 菜单 → pengurusan sahsiah → pengurusan kehadiran
4. tabguru 点名页 → 检查学生 → Kemaskini → 弹窗确认 → Sahkan → 再确认

## 方案

1. **书签直达**（省掉步骤 2-3）：
   收藏 `https://moeispel.moe.gov.my/sahsiah/kehadiran/tabguru`
   登录 session 由浏览器保持，日常直接打开书签就在点名页。

2. **一键点名面板**（`moeis-kehadiran.user.js`，Tampermonkey 用户脚本）：
   页面右下角注入悬浮面板：
   - 实时显示：已到 / 缺勤 / 总人数 / 日期
   - **✔ 全勤一键确认**：全班都到 → 1 次点击完成保存+确认
   - **✅ 保存并确认**：有缺勤（先在原表格取消勾选缺席学生并选原因）→ 一键提交确认
   - **💾 仅保存**：只保存不确认
   - 提交复用系统自身流程（点 Kemaskini → 自动点 Sahkan → 自动关成功提示），保证数据格式与官方一致

## 安装

1. Chrome 装 Tampermonkey 扩展（Chrome 网上应用店搜 Tampermonkey）
2. 打开 Tampermonkey 图标 → 添加新脚本 → 全选删除 → 把 `moeis-kehadiran.user.js` 全部内容粘贴进去 → Ctrl+S 保存
3. 登录 MOEIS 后打开点名页，右下角出现「📋 点名快捷面板」即成功

## 日常使用

| 场景 | 操作 |
|------|------|
| 全班出席 | 打开书签 → 点「✔ 全勤一键确认」→ 完 |
| 有人缺席 | 打开书签 → 原表格取消勾选缺席者 → 选缺勤原因 → 点「✅ 保存并确认」|
| 未登录被踢回 | 正常登录一次（登录页填好 IC 后按 Tab 直接输密码即可），之后仍保持会话 |
